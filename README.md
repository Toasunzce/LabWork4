# Лабораторная работа №4
## Взаимодействие процессов (потоков): взаимное исключение и синхронизация

## Вариант 20: Приоритетные заявки

Многопоточная модель конвейера `Generator -> Stage 1 -> Stage 2 -> Stage 3 -> Collector`.
Заявки имеют приоритет HIGH или NORMAL. Реализованы два режима обслуживания очередей:
FIFO и приоритетный (не более трёх HIGH подряд при наличии ожидающих NORMAL).
Синхронизация: Critical Section и Semaphore. 
Программа выводит журнал событий,
статистику и количество нарушений инвариантов.

## Требования к среде выполнения

- ОС: Windows (выполнение проводилось в системе Windows 11)
- Компилятор: MSVC (сборка в среде выполнения Visual Studio)

## Параметры запуска

| Параметр | Описание | Значение по умолчанию |
|----------|----------|-----------------------|
| `--mode` | режим обслуживания очередей: `fifo` или `priority` | `priority` |
| `--high-share` | доля HIGH-заявок, % | 20 |
| `--requests` | количество заявок | 500 |
| `--workers` | рабочих потоков на каждой ступени | 2 |
| `--seed` | начальное значение генератора случайных чисел | 1000 |
| `--timeout-ms` | максимальная длительность эксперимента, мс | 60000 |
| `--verbose` | подробный журнал событий (0 отключает вывод для измерений) | 1 |
| `--csv` | файл для сохранения результатов запуска | не сохраняется |

## Проведение эксперимента

1. Стандартные параметры: 500 заявок, 2 потока на ступень, режимы `fifo` и `priority`,
   доля HIGH 20% и 70%, по 3 запуска каждой конфигурации.
2. Индивидуальные параметры. STUDENT_ID это последние 3 цифры студбилета:
   `SEED = 1000 + STUDENT_ID * 97`, `OPERATIONS = 500 + STUDENT_ID * 5`.
3. Построение графиков по данным из `data\`.
